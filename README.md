# Progressive Portfolio Project

Personal portfolio of **Bert Denzel G. Elegino**, BS Information Technology, built step by step with HTML, CSS, and JavaScript.

## Activities
| Activity | Section | What it adds |
|---|---|---|
| 1 | Intro | Name, tagline, photo |
| 2 | About me | Bio, hobbies, background |
| 3 | Skills | Skill cards in a CSS Grid |
| 4 | Projects | Featured project plus project cards |
| 5 | Education & experience | Two timelines |
| 6 | Menu | Sticky navigation bar |
| 7 | Contact | Contact form |
| 8 | Phone responsiveness | Menu button and small-screen layouts |
| 9 | Final portfolio | Footer, README, cleanup |

## Files
- `index.html` - page structure
- `style.css` - styling, grouped by activity
- `script.js` - contact form, phone menu, footer year
- `images/` - profile photo

## Run it
Open `index.html` in a browser.
